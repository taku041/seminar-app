◆セミナーアプリ(架空の2027年開催セミナー情報50を管理・主にPC向け)<br>

◆Seminar App<br>
Seminar Appは、IT・DX・AI関連のセミナーやイベント情報を見やすく一覧表示するシンプルなWebアプリケーションです。月別の表示やキーワード検索機能等を備えています。<br><br>


◆主な機能<br>
📅 セミナー一覧表示。日付の早い順にソート。初期状態は18セミナー表示。<br>
📅お申込みページ（seminar.html）。sessionStorageで選択した情報を維持。<br>
📅「もっと見る」を実装。12イベントずつ追加表示。<br>
🔍 キーワード検索。検索ボタンクリックまたはENTERイベントで検索。検索窓の右側に×（クリアボタン）を表示。<br>
🏷️ 月別表示（セレクトボックス。「現在選択されている月」を横に表示）<br>
✉メールアドレスをチェック（バリデーション）。<br>
⚡ 軽量・高速表示。<br><br>


◆本アプリは以下のような用途を想定しています。<br>
・セミナー情報のポータルサイト<br>
・社内勉強会・イベント一覧<br>
・各種コミュニティ内のイベント紹介

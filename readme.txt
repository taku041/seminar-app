セミナー管理アプリ(架空の2027年開催セミナー情報50を管理・主にPC向け)

▼実装機能一覧
・一覧表示（コンポーネント1つ作成。早い順にソート。3カラム表示。初期状態は20セミナー表示）
・月ボタン別フィルタリング（セレクトボックス。「現在選択されている月」を横に表示）
・キーワード検索（検索ボタンクリックまたはENTERイベントで検索。検索窓の右側に×（クリアボタン）を表示）
・「もっと見る」を実装（「もっと見る」ボタンクリックで12イベントずつ追加表示（フェードインアニメーションでふわっと表示を演出））
・お申込みページ作成（seminar.html）。sessionStorageで選択した情報を維持。
・メールアドレスをチェック（バリデーション）。
